# EsportsRosterBot

Telegram bot to register esports teams: captains submit 5-player rosters with optional subs, payments optional, admins resolve ID conflicts and manage a live match table.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
